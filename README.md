# dArchwin
A MacOS inspired splash screen for [plymouth](https://github.com/droidian/plymouth) featuring a white loading pill underneath the Arch Linux logo.

## Install
```bash
cd /usr/share/plymouth/themes && \
sudo git clone https://github.com/areyoufeelingitnowmrkrebs/darchwin && \
sudo plymoth-set-default-theme -R darchwin
```
